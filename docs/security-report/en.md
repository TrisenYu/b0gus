### Security Report
As the project has not yet been taken over by the community, 
no CVE IDs will be assigned for the time being.

However, if there is indeed a serious vulnerability, please 
email [jajune257@gmail.com](mailto:jajune257@gmail.com) and follow the table format below in your email.


|        Email Section	         |                                          Content                                          |
|:-----------------------------:|:-----------------------------------------------------------------------------------------:|
|        Email Subject	         | [Vulnerability Report] b0gus’s [component] has a [Low/Medium/High] severity vulnerability |
| Brief Description of the Flaw |            	A short description of the vulnerability and its potential impact             |
|         Environment	          |                       Provide the environment where the flaw exists                       |
|      Steps to Reproduce	      |                       Describe step by step how to trigger the flaw                       |
|   Possible Fix (optional)	    |                                   Suggested ways to fix                                   |
